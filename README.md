Para executar o arquivo sh, primeiro é necessário torná-lo um executável:

    chmod +x OpenCalculadora.sh

Depois execute com:

    ./OpenCalculadora.sh

Esse arquivo irá executar a calculadora.py, uma calculadora interativa desenvolvida em python que oferece operações matemáticas básicas.

Funcionalidades:
    Soma - Adição de dois números
    Subtração - Subtração de dois números
    Divisão - Divisão de dois números
    Multiplicação - Multiplicação de dois números
    Reescolha de números - Permite alterar os valores sem reiniciar o programa
    Sair - Encerra o programa de forma segura

Como usar:

1. Execute o programa
2. Insira o primeiro número
3. Insira o segundo número
4. Escolha uma opção matemática no menu:
    1 - Soma
    2 - Subtração
    3 - Divisão
    4 - Multiplicação
    5 - Escolher números novamente
    0 - Sair

Requisitos:
    Python 3.x ou superior
    Nenhuma biblioteca externa necessária
